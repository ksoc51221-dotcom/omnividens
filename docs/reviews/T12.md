# T12 review: terminal mode (`reelay try`)

**What:** `reelay try <link | video file | "instruction"> [--no-input] [--debug]`. Code in `reelay/terminal/` (`runner.py`, `netfail.py`); one dispatch branch plus a help line in `reelay/installer/cli.py`. Reuses `Pipeline` + `default_deps()` with `UserQueue(inline=True)`; user id `terminal`; default profile, no quiz.
- Arg type: existing file → file, `http(s)://` → link, else instruction.
- Buttons print as `1) Adopt  2) Skip`; the choice goes to `Pipeline.decide` / `.confirm` (same routing as `PipelineBot.handle_button`). `--no-input` or non-TTY stdin: list and don't wait.
- Output: HTML tags and control characters (terminal escapes) stripped; 🧾 receipt kept.
- Network failures (gaierror, SSL, timeouts, httpx/urllib) → one sentence naming the host, no traceback unless `--debug`, no bypass advice.

**Test:** `python -m pytest -q tests/test_terminal.py` (16 fake-only tests); full suite 326 pass.

**Unsure:** host naming when the error carries none falls back to the link's host; the video module hides its network causes (see REQUESTS.md).
