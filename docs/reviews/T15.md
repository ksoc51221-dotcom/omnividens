## (2) Token handling — good, one real hole
Token goes only into `build_env`; absent from argv, files, logs and the report; `_TOKEN_OK` rejects whitespace/newlines. Tests assert env vs argv vs run-dir files vs output vs `repr(res)` vs report `fit`/`logs`, for subscription, non-JSON output and local.
- **FIX-1 (small leak):** `runner.py` non-JSON path does `redact((stderr or stdout)[-500:], secrets)`: it slices first, then redacts. If the token straddles the 500-char boundary, the exact-match replace fails and the token's tail is returned and shown. Redact first, then slice (`redact(stderr or stdout, secrets)[-500:]`). Add a test with the secret placed across the boundary.
- NIT-4: redaction is exact-string only (not URL-encoded, split, or partial forms). Fine given no tools; mention in docs.
- NIT-5: `The trial run crashed: {e!r}` is not redacted; exceptions from `launch` don't carry env today, but a one-line `redact` is free.

## (3) Routing, escalation, daily cap

## (5) Performance — **FIX-2**
`pipeline.py:353` runs `MAX_TRIALS = 3` candidates one after another inside one job on the user's queue (`UserQueue`: one job at a time per user). Local timeout is `max(timeout, 600)`. Worst case per video: 3 × 600 s = **30 min** of local runs; with light-skill escalation each failure adds a Claude run (up to ~180 s), about **39 min**. During that, the owner's other messages (`/forget`, new links, instruction taps) wait, and the Mac's CPU/RAM is pinned. Typical case (295 s) is ~15 min for three.
Cheapest mitigations, in order of effort:
1. **At most 1 local trial per video** (the rest go to Claude if allowed, else scan-only with the reason). Needs a per-video counter passed into `run_trial` (an `allow_local` flag) or kept in the pipeline loop. Caps the worst case at ~10 min + Claude runs.
2. **Send a heads-up before a local run** ("testing on your Mac, can take ~5–10 min") so the silence isn't read as a hang. One message.
3. Try the qwen3 soft switch: append ` /no_think` to the prompt for local only, then re-measure (unverified that it survives Claude Code's Anthropic-compat layer; measure before trusting). A smaller model (`qwen3:4b`) is the fallback lever.
4. Lowering the 600 s timeout alone is wrong: 295 s was measured, so a lower cap just turns slow-but-working runs into failures and triggers escalation.
Recommendation: do 1 + 2 now; 3 only if it measures well.
