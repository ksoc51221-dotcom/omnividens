# T25 Mac fallback for blocked YouTube links (review request)

Branch `agent/t25-mac-fallback`, cut from `agent/t20-reports`. Not pushed. Reviewer: append BLOCKER / FIX / NIT below.

## What it does
Cloud `prepare` gets yt-dlp's bot check (`BlockedError`) → `POST /api/defer` → relay queues the job and tells the user → the owner's Mac (`reelay mac-worker --once`, launchd every 60 s) claims it, fetches the video, uploads ≤20 frames (≤50 KB JPEG) + transcript → relay fires the routine with the original JOB + `bundle_id` → `prepare` fetches and validates the bundle and writes `bundle.json` itself. Everything after is unchanged. The Mac runs no model; the video never leaves it.

## Files
- `reelay/video/errors.py`, `download.py`: `BlockedError`, `RateLimitedError`, `BadLinkError`; `cloud_message` wording; `--sub-langs en,en-US,en-GB,en-orig`; all yt-dlp retries off; `pick_subtitle` takes whichever `.vtt` arrived.
- `reelay/cloud/prepare.py`, `job.py`, `relay.py`: defer path (never when `bundle_id` is set), bundle path (`BadBundle` on bad JPEG magic, size, count, base64, fields).
- `reelay/cloud/mac_worker.py`: poll/handle/upload, frame shrink, local-only Whisper (`local_files_only=True`, never Groq), launchd install/remove (label `com.reelay.macworker`, `StartInterval` 60, no `KeepAlive`). `reelay/installer/cli.py`: `mac-worker` dispatch + help line only.
- `relay/app.ts`, `main.ts`, `deno.json`: routes, lease, sweep, cron (guarded). Rate cap and routine fire were extracted into `takeRateSlot` / `fireRoutine`, same behaviour.
- Docs: `docs/CLOUD-SPEC.md`, `docs/SETUP-CLOUD.md`, `routine/PROMPT.md` (20 frames for Mac jobs, notes), `reelay/video/NOTICE`.

## Decisions to check
- `MAC_SECRET` is checked only in `macApi` (`/api/mac/*`); `api()` checks only `RELAY_SECRET`. Test: "secret scoping".
- `/api/defer` accepts only the owner's chat id, no `file`, no `bundle_id`, one entry per `update_id`. Loop guard exists on both sides (relay 400, prepare `_defer_to_mac`).
- Fail messages are built by the relay from a fixed table; the Mac sends only a reason code and a sanitised host.
- KV row outlives the 24 h logical expiry (48 h) so the sweep can still tell the user. Rate cap full at bundle time: bundle waits, next sweep fires.
- `NetworkError.user_message` (local, hotspot advice) kept; `cloud_message` is used by `prepare`. `reelay/bot/core.py` `download_failed_reply()` still says "screen recording" (not my file; `test_bot.py` still asserts it). The pipeline path uses `e.user_message`, so local mode already shows the new wording.

## Not tested live

## Owner does by hand
Follow "Optional: Mac fallback" in `docs/SETUP-CLOUD.md`: `openssl rand -hex 32`, set `MAC_SECRET` in the Deno console and redeploy, add `relay_url` and `mac_secret` to `~/.reelay/config.toml`, run `reelay mac-worker install`. Redeploy is needed for the new routes.
