## What it does
1. `adopt_line()` now returns a clone line only for safety YES with no code (those get Adopt/Skip). New `manual_line()` covers UNSURE with code (same identity, type and file-evidence rules, strict URL via `adopt_line_for`): no buttons, `adopt_line` sent to the relay is null; the report text warns the code can't be judged and wasn't read or run, points to the files named in the safety line, and shows the clone line to run by hand. NO, unconfirmed identity, UNSURE without code, apps and unclear: no line, as before. `adopt_note` only exists for the button case.
2. `routine/PROMPT.md`: if the video has any GitHub candidate, skip claim checking (`claims: []`, no web search, no timestamps); otherwise fact-check as before. `info` is now only `what` (exactly 2 sentences); `impact.why` asks for how it helps that project and a suggestion to implement it there. Hard rules and clone limits unchanged.
3. Reports drop problem, pros, cons, examples (old JSON with them still parses, fields ignored). Impact reads "Could help <project>: <why>" or "Doesn't fit any of your listed projects."
4. Token usage is measured in `apply_gate` by `measure_skill_tokens`: our own clone, `SKILL.md` files only, no `.git`, no symlinks, sizes only (bytes / 4), max 20 files and 5000 entries. One file: "About N tokens each time it loads (measured from SKILL.md)". Several: count and smallest-to-largest range. None: the model's number, labelled estimate.
