   `find_problem` returns **None**. The same bypass works for the older `hooks:` check. Fix: take the block between the
   opening `---` line and the next line that is exactly `---` (e.g. `re.match(r"﻿?\s*---\r?\n(.*?)\r?\n---\s*$", text, re.S|re.M)`),
   or fail closed and scan every line of the file for `^\s*"?allowed-tools"?\s*:`.
