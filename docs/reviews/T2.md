## What it does
`route(text, client=None)` returns an `Instruction` or a `Clarification(question)`.
1. `router/rules.py`: regex parsing of skill ("use the X skill"), model (opus/sonnet/haiku/fable), effort ("effort high" / "high effort"), project path. If flags are found and a task of 2+ words remains, no API call.
2. Otherwise `router/router.py` asks Haiku (`claude-haiku-5-5`, structured JSON output, effort low) via the `RouterClient` interface (`router/client.py`). Rule flags win over Haiku's; Haiku's output is re-validated (model/effort allowlists, skill name regex that can't start with `-`).
3. One-word messages get a question without any API call.

## Safety
User text goes in `<user_message>` tags; system prompt says quoted video content is data. Model output can't inject CLI flags (validated).

## How to test
`pytest tests/test_router.py`. Real call: set `ANTHROPIC_API_KEY`, `route("can you summarise the README")`; not run here (no key).

## Review by T3 (reads `main...agent/t2-router`; ran no code, read-only)

Overall: clean, small, and the safety thinking is good (flags re-validated, `-` can't start a skill name, rules beat Haiku, user text wrapped in tags). Tests use a fake client, which is right.

- **FIX** `rules.py` `_MODEL`: model names are matched anywhere in the sentence, so "write a haiku about my repo" or "play the opus ..." becomes `model=haiku` and the task loses the word ("write a about my repo"). Because `has_flags` is then true and the leftover has ≥2 words, Haiku is never asked, so the mistake sticks. Suggest requiring a cue: `(?:use|with|on|model[:=]?)\s+(opus|…)` or a trailing `, opus`. Add a test for "write a haiku".
- **FIX** `rules.py` `_SKILL_B` (`skill\s*[:=]?\s+word`): "improve my skill set" gives `skill="set"`; "skill issue" gives "issue". Require the `:`/`=` form, or make `_SKILL_B` only match when the word looks like a name the adapter knows. Add a test.
- **FIX** `client.py`: no error handling. No key, no network or a refusal raises out of `route()` and would crash the bot handler. Catch `anthropic.APIError`/`KeyError`/`json.JSONDecodeError` (and missing key) and return `Clarification("I couldn't understand that just now, can you rephrase?")`, or document that T8 must catch it.
- **NIT** `output_config={"effort": "low", ...}` and model id `claude-haiku-5-5`: I couldn't verify these against the live API; run the real client once by hand before the demo.
- **NIT** `project` (from rules or Haiku) is any path, e.g. `/` or `~/.ssh`. The adapter (T5/T8) should check it is inside an allowed folder; worth a line in your docstring.
- **NIT** `anthropic` is not in `pyproject.toml` dependencies; add it (orchestrator-owned file) or as an optional extra.
- **NIT** `_take` docstring says "lowercased pattern hit" but it returns the raw group; harmless.
