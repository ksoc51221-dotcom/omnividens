## What it does
- `quiz.py`: pure functions. 3 button questions (night/claims/detail) + optional free-text goals. Callback data `quiz:<qid>:<key>`; `QuizState` is a plain dataclass the bot keeps per user. `build_profile` → `Profile` (vibe from "night"; traits `claims`, `detail`).
- `store.py`: `reelay_home()/profiles/<id>.json`, dir 0700, file 0600, atomic write; user id sanitised (no path traversal); corrupt file → None; bad vibe repaired.
- `commands.py`: `/profile`, `/vibe [x]` (+ `vibe:<x>` buttons), `/forget`, `/quiz`, `finish_quiz`. Returns `Step(text, buttons, wants_text)` (same shape as bot `Reply` → T8 maps it).
- `tone.py`: `prompt_line(profile)` system-prompt fragment, `style(text, profile)`, `learn(profile, text)` counts topics as `interest_<topic>` traits (visible in `/profile`).

## T6 review of agent/t7-profile (read-only; 118 tests pass on the branch)
Read all of `reelay/profile/` plus tests. Quiz/store/commands are clean: id sanitising, 0700/0600, atomic write, stale or forged callback data rejected, no network, nothing executed.
- **FIX `tone.learn` can crash.** `int(profile.traits.get(key, "0") or 0)` raises `ValueError` if the stored value isn't a number (hand-edited or corrupt file; verified with `interest_tech = "abc"`). `learn` runs on every user message, so the bot would error each time. Parse in try/except and reset to 1; also cap the count (e.g. 9999).
- **FIX `describe()` says "it lives only on your computer", which is not fully true.** T6 sends goals, vibe and traits to Claude (Claude Code login or API) as part of the fact-check prompt. Reword: "stored only on your computer; goals and vibe are included when I ask Claude to check a video".
- **FIX `store.load` doesn't bound sizes.** `goals` can be a string (iterates characters) or hold thousands of long items; traits values can be huge. T6 caps what it sends, but `/profile` would print all of it. Require `goals` to be a list, keep at most 5 goals × 300 chars and 20 traits × 100 chars.
- **NIT** `_path` maps `a/b` and `a_b` to the same file (verified). Harmless for Telegram numeric ids; mention in a comment, or add a short hash suffix if ids can ever be non-numeric.
- **NIT** `/forget` removes the JSON only: a leftover `.tmp` (crash during save) and the bot's in-memory `QuizState` survive. Delete the tmp too; T8 should drop the QuizState.
- **NIT** `style()` for `chill` replaces every `!` in the text, which would mangle URLs or code inside a report. Apply it only to the bot's own fixed strings (as the docstring says) and note that in T8 wiring.
- **NIT** `tone.prompt_line` is a prompt fragment built from fixed strings only (good: no user text reaches a system prompt). Keep it that way; free-text goals must stay inside a data block, as T6 does.

No BLOCKER. Fix the three FIXes, then I consider it approved (no re-review needed).
