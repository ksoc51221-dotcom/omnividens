# T23a review notes: cloud relay

**What:** `relay/` Deno Deploy relay (main.ts, app.ts, app_test.ts, deno.json, README.md) implementing every route in the CLOUD-SPEC contract.

**Test:** `cd relay && deno task test && deno task check && deno task fmt` (16 tests, fake fetch, in-memory KV).

**Unsure / for the reviewer:**
- `OWNER_TELEGRAM_ID` counts as "required" on the status page; with it missing the page shows not connected, but the webhook is still set so `/start` works.
- Rate counter uses get+set (not atomic); a race could allow a few extra runs per hour. Fine for a single owner.
- `/telegram` returns 200 even on internal errors because the update_id is already deduped (a Telegram retry would be dropped anyway).
- Files are streamed from Telegram; the 20 MB check uses getFile's `file_size` and Content-Length, not a byte counter.
- Not run on real Deno Deploy; verify KV availability on the free plan.
- Messages with a photo only (no video/document/animation and no text) are ignored.
