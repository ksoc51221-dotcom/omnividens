# T1 review: video pipeline

Branch `agent/t1-video` · owner t1-video · reviewer T2

## What it does
`from reelay.video import load_video` → `load_video(url_or_path, work_dir=None) -> VideoBundle`.
- `download.py`: yt-dlp (≤720p, mp4, native subs + info json → caption = title + description). Success is judged by "video file exists", not exit code.
- `frames.py`: ffmpeg frames every 2 s + scene cuts (>0.4), near-duplicates dropped, capped at 30 (evenly thinned), 512 px wide JPEGs.
- `transcript.py`: native VTT first (rolling duplicates collapsed, `[m:ss] text`); else Groq Whisper if a key is in `GROQ_API_KEY` or `~/.reelay/config` and the file has audio. Whisper failure → empty transcript, no crash.
- `errors.py`: `DownloadError` / `FrameError`, each with `.user_message` (download one asks for a screen recording).
- `NOTICE`: credit to claude-video (MIT). Code is a fresh rewrite, nothing copied verbatim.

## How to test
```
python -m venv .venv && .venv/bin/pip install pytest && .venv/bin/pytest tests/test_video.py
```
9 tests, tiny ffmpeg `testsrc` clips, no network (the one download test hits a closed local port).

- Subtitle languages are English only (`en.*`).
- Non-mp4 downloads (webm) are merged to mp4; Instagram carousels / image posts will raise `DownloadError`.

### T2 review (read the diff of `agent/t1-video`; did not run tests)
Clean and readable, good error messages, the "judge by file, not exit code" detail is smart. No blockers.

- **FIX** `download.py` / `is_url`: any `http(s)` URL is passed to yt-dlp, including `http://localhost:…` or `http://192.168.x.x/…`. A pasted link could make the user's machine fetch internal addresses. Reject hosts that are localhost / private IPs (use `ipaddress` on the hostname) before calling yt-dlp.
- **FIX** `download.py`: no size or length cap. A 3-hour livestream VOD would download for the full 180 s timeout and fill the disk. Add `--max-filesize 200M` and `--match-filter "duration<=600"` (pick a limit) and raise a `DownloadError` with a friendly message.
- **FIX** `pipeline.py`: a local `source` is any file path. Fine if only the bot passes files it saved itself, but document that T3/T8 must never pass user-typed text as `source`, or a Telegram user could point it at any file on disk. A one-line docstring is enough.
- **NIT** `transcript.py`: audio is sent to Groq. That is the right call as an opt-in, but README/docs should say it clearly (project is "local-first"). Also whisper fails silently on files over Groq's 25 MB limit (~50 min at 64 kbps); fine with a duration cap.
- **NIT** `core/types.py` `VideoBundle` says content is data; `caption` and `transcript` are untrusted. Consider a short comment in `load_video` docstring so T6/T8 remember.
- **NIT** `frames.py`: one ffmpeg process per frame (up to 30) plus a full scene-detect pass; fine for short clips, slow for long ones. The duration cap above fixes this.
- **NIT** `work_dir=None` temp dir is never cleaned (already in your open questions): let T8 own cleanup.
