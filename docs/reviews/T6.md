## What it does
`fact_check(bundle, profile, backend=None, config=None) -> Verdict`, never raises.
- `prompt.py`: untrusted-data block with a random per-call delimiter; frames capped at 12 (no symlinks), transcript 20k chars, caption 2k, control chars stripped. Profile goals/traits are also inside the block. Tone follows `profile.vibe`.
- `backends.py`: `ClaudeCodeBackend` (default, `factcheck_backend = "claude-code"`) and `ApiBackend` (`"api"`, model `claude-sonnet-5-5`, tool `web_search_20250305`, images as base64). Other config keys: `factcheck_timeout_s` (300), `factcheck_model` (validated with `check_name`).
- `parse.py`: strict JSON validation. Unknown verdict → `unverified`; true/false/misleading with no valid source → `unverified`; sources and candidate URLs go through `sandbox.fetch.check_url` (https, no creds, no private host); caps (10 claims, 5 candidates, 5 sources); `time_s` outside the video → None; duplicates dropped; wrong types ignored.
- `check.py`: every error (timeout, missing claude, bad config, bad JSON) → safe Verdict with an honest summary.

## claude-code lockdown
`claude -p --output-format json --no-session-persistence --permission-mode dontAsk --strict-mcp-config --tools Read,WebSearch,WebFetch --disallowedTools Bash,Write,Edit,NotebookEdit,Task --allowedTools Read(//<frames dir>/**),WebSearch,WebFetch --add-dir <frames dir>`. Prompt goes in on stdin. cwd is a fresh empty temp dir (no project CLAUDE.md). Process group is killed on timeout (reuses `adapters.base.subprocess_runner`).

## T7 review of agent/t6-factcheck @ a2e7233 (read-only; I ran probes against `good_url` / `parse_verdict`)
Good: random-nonce data block, `_clean` strips control chars, fixed `CLAUDE_TOOLS = Read,WebSearch,WebFetch` plus `--disallowedTools` Bash/Write/Edit/Task, `dontAsk` mode, `--strict-mcp-config`, empty temp cwd, Read limited to frame dirs, symlinked frames dropped, model/binary names validated, every backend exception → `failed()`. Probes: `127.0.0.1`, `localhost`, `169.254.169.254`, `[::1]`, `[::ffff:127.0.0.1]`, decimal/hex/short IPs, `user@127.0.0.1`, `*.localhost` all rejected; NaN/inf `time_s` and non-JSON/nested garbage give a safe Verdict.

No tool outside Read/WebSearch/WebFetch is reachable, so no Bash/Write/Edit. Findings:
- **FIX WebFetch is unrestricted and runs on the user's machine.** The "public https only" rule is only a sentence in the prompt. A video saying "fetch http://localhost:8080/… or https://attacker/?q=<goals>" can steer the model there (local services, cloud metadata, or leaking profile goals in a URL). Cheapest fix: drop `WebFetch` and rely on `WebSearch` (add it back only if tests show checks get much worse); otherwise state this residual risk in the review/README. Same idea for the API backend: it only has `web_search`, which is fine.
- **FIX `good_url` fails open on names that don't resolve.** `https://metadata.google.internal/`, `https://foo.internal/`, `https://printer.local/` pass (verified) because `is_private_host` returns False when DNS fails. Add a suffix block (`.internal`, `.local`, `.lan`, `.home`, `.corp`, `.intranet`) and require a dot in the host. A name that resolves later to a private IP (DNS rebinding) is only safe if T4's sandbox fetch re-checks at clone time — it does call `check_url`; keep that.
- **FIX `summary` and claim `text` are free model text that can carry injected content** (e.g. a phishing link or fake "official" instruction echoed from a video). Strip URLs from them (sources/candidates already carry vetted URLs), and T8 must send them as plain text, never with Markdown/HTML parse mode.
- **NIT** A claim can be `true` with a source the model got from the video itself, so "true + any public URL" is not proof. Say "sources cited by the model" in the report, not "verified".
- **NIT** `https://evil.com/\@127.0.0.1` passes (host parses as evil.com). Harmless here but parsers disagree on backslashes; reject `\` in URLs.
- **NIT** User-level `~/.claude` settings, hooks and CLAUDE.md still load even though cwd is empty. Consider `--disable-slash-commands` and `--setting-sources` (check `claude --help`) so a user hook can't run in this unattended call.
- **NIT** API backend skips frames over 4.5 MB but the prompt still lists them ("image N" numbering shifts). Filter frames before building the prompt.
- **NIT** `good_url` does a DNS lookup per URL (up to ~55 per Verdict), synchronous. Cap total URLs checked or cache by host.
- **NIT** Frame images are untrusted too (on-screen text), but sit outside the delimited block; the rule text covers them, fine, just keep the rule.

No BLOCKER. The three FIXes should land before merge.
